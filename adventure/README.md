# Die verstummte Glocke

## Kurzfassung

Ein Aushang des Barons von Dornfels verspricht hohe Belohnung, wenn die Gruppe im alten Wachturm in den verfallenen Außenbereichen die verstummte Glocke wieder läuten lässt. Der sichtbare Fluch verdeckt Goldgier, heimliche Bergungsversuche und eine Glocke, die aus geraubtem Gold gegossen wurde. Der One-Shot ist lösbar, sobald weitere Bergungen gestoppt, die zentrale Wahrheit belastbar erkannt und die Zukunft der Glocke entschieden ist.
